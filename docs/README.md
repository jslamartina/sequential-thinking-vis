## Archived Documentation

Historical documentation and planning documents are stored in `archive/`:

- **[Plans](archive/plans/)** - Implementation planning documents
- **[Thought Trees](archive/thought_trees/)** - Sequential thinking visualizations from development

### Archive Naming Convention

All archived documents use minute-precision timestamps:

```
YYYY-MM-DD_HHMM_DESCRIPTIVE_NAME.md
```

Example: `2025-10-24_1938_OBSERVER_MODE_IMPLEMENTATION_PLAN.md`
